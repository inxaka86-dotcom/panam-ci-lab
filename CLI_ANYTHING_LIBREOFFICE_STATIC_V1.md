# CLI-Anything LibreOffice public exact-source qualification V1

Status: `PUBLIC_ONLY / EXACT_SOURCE_RESEARCH / NO_UPSTREAM_EXECUTION / NO_PRIVATE_REPO_ACCESS`

This public CI workload binds selected files from `HKUDS/CLI-Anything` to exact commit:

`810c18b0d1ab9b234bc996c9fd999318523a3ef0`

It answers one narrow question: are the exact upstream files reviewed by PANAM the same files acquired by public CI, and do they retain the expected structural markers needed for a later isolated synthetic pilot?

## What this job proves

- this repository's public-only publication gate passes;
- selected public upstream files are downloaded only at the exact commit;
- their Git blob identities match the reviewed blobs;
- the selected LibreOffice backend still contains its bounded headless flag set and temporary LibreOffice profile pattern;
- the export module still contains its preset map;
- the importer still contains its explicit Office conversion map and `defusedxml` dependency marker.

The exact-source binding lets PANAM's human/repository review refer to stable upstream bytes rather than to a moving branch.

## What this job does not prove

This public job deliberately does **not** attempt to re-implement a security scanner for arbitrary Python source and does not claim that structural markers by themselves make the upstream harness safe to execute.

In particular, the job does not itself prove the absence of every dangerous execution primitive, full path containment, full argument validation, dependency safety, or sandbox safety. Those are separate review/execution gates.

## What this job does not do

- it does not clone or access any private PANAM repository;
- it does not install CLI-Anything;
- it does not install or execute LibreOffice;
- it does not import upstream Python modules;
- it does not run upstream agent commands, REPLs or tests;
- it does not use real documents, user data, credentials or production systems;
- it does not publish packages;
- it grants no merge, deployment or production authority.

## Reviewed upstream properties and PANAM gaps

Separate review of the exact blob-bound sources identified useful upstream engineering controls, including an AI-agent threat model, guidance against shell execution, temporary LibreOffice profile isolation, bounded normal export presets, an import-extension map and `defusedxml` parsing.

The same review also identified surfaces PANAM must keep denied in the first pilot: REPL/session persistence, package installation/publishing, existing-document import, overwrite, broad file-path selection, and any authority outside a dedicated sandbox.

Those findings are review conclusions about the exact blob-bound source. They are not generated by this CI workflow and do not authorize execution.

A PASS means only that the reviewed upstream bytes were acquired and structurally bound successfully. It is not an adoption decision.
