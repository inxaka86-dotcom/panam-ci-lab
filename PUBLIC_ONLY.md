# Public-only repository boundary

Everything in this repository must be safe to publish to the internet.

Do not add:

- secrets, tokens, private keys or credentials;
- private PANAM source code or repository history;
- production topology, hostnames, IPs, cloud project identifiers or database details;
- real documents, user data, logs, receipts, incidents or confidential fixtures;
- workflows that require private repository access or production permissions.

Use synthetic data only.
